# ProjectForge VS Code Extension

ProjectForge is an enterprise-grade project scaffolding engine for VS Code.  
It generates full-stack, backend, frontend, bot, desktop, monorepo, and extension templates using an advanced multi-step wizard.

## Features

- Full-stack project generation
- Backend templates (Express, FastAPI, NestJS)
- Frontend templates (React, Next.js)
- Bot templates (Discord, Telegram)
- Desktop templates (Electron, Tauri)
- Monorepo templates (Turborepo, pnpm workspaces)
- VS Code extension template generator
- Advanced wizard UI
- Health checks & upgrade engine
- Git integration
- Workspace manager
- AI-assisted generation (future)
